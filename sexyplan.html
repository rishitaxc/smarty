The demo · 5 minutes · one take

The script.

One laptop on the projector. One story. Every beat has what's on screen, what's said, and the points it earns.

0:00

Cold open: the alarm ingest

Screen: a dark wind-farm dashboard (our own web page) with 12 turbine tiles. The tiles replay real SCADA data at 60× speed. T-07 turns red with a soft alarm sound, and the Sidekick notch slides down.

Pip: "Turbine seven's gearbox vibration just hit three times baseline. Want me to look?" · You: "Show me."

0:25

The turbine builds itself over the screen originality

Screen: full-screen transparent overlay. The tower, nacelle, hub and blades appear part by part as Pip names each one, with the blades turning. Then the nacelle splits open (Spread): main shaft → gearbox → high-speed bearing glowing red. A live vibration sparkline floats beside the part.

"This is the high-speed shaft bearing. It spins at about 1,500 rpm, and it's the part that's hurting."

1:15

Scout investigates, with receipts explainability decide

Screen: a task board slides in: Scout · Researching. Evidence cards appear one by one: a 30-day bearing-temperature trend, the last maintenance record, and the OEM manual page with a highlighted line. Then the diagnosis card: "Bearing wear · ~9 days to failure · confidence 0.82", each claim linked to its evidence.

"I'm not guessing. Here are the three signals, and here's the manual page that says what they mean."

2:00

Bolt does the work, and you watch it happen act originality

Screen: Bolt opens the maintenance system (our own CMMS page). Pip's cursor flies to each field as Bolt fills it: asset T-07, part SKF bearing, technician. Scout pulls the real wind forecast and Bolt picks Thursday 06:00–10:00, the lowest-wind window (least energy lost). The cursor stops at Submit, which is greyed out: "Needs approval".

"I've scheduled it for the calmest four hours this week. That costs us about ₹11k of energy instead of a month of downtime."

2:50

The governance moment: denied, then approved role-based human approval audit

Screen: you say "approve" as Operator and get a red toast: "Operators can't approve spend over ₹50,000. Escalating to Supervisor." Switch role to Supervisor and a Touch ID prompt appears. Touch the sensor and it's approved. An audit log entry slides in with the timestamp, approver, evidence IDs and a hash chained to the previous entry.

"Nothing leaves the building without a human. And every step is on the record."

3:35

The ROI counter ROI report

Screen: Pip draws the outcome on a sketch board: unplanned failure vs planned fix, with a big ₹ counter rolling up to the energy saved. A one-page PDF report is generated and opened.

"Planned: four hours. Unplanned: weeks, waiting for a crane. That's the difference on one turbine."

4:15

The mic drop: swap the asset reusability

Screen: you drop chiller_pump.yaml into Sidekick. The same three agents build a 3D hospital chiller pump, find a seal leak, and draft a work order. Final card: "One agent pattern. Any rotating asset. Energy · Manufacturing · Healthcare · Transport."

"We didn't build a turbine app. We built a maintenance crew that you give a new asset file."

4:50

Freeze frame

The turbine keeps spinning in the corner while you take Q&A, which keeps the room watching.

The moments people will film

Five "wait, what?" moments.

The 3D turbine builds itself over the dashboard

No window and no frame. It looks like it's floating on the screen. Your friend's reaction in the videos ("Oh my days") is the reaction you want here.

The nacelle splits open and the bearing glows

The Spread view already exists in our 3D code. A pulsing red emission material does the rest.

The cursor fills the work order by itself

Pip's cursor moves across the screen and fills fields. People recognise it as "the AI is using the computer."

The AI gets refused

Showing the agent being blocked scores more governance points than any slide. Then Touch ID, which is a physical, real action.

"Now do a hospital pump"

The swap proves the work is reusable in about 20 seconds. That's the CGI accelerator answer, shown live instead of claimed.

The crew

Multi-agent, and every agent has a visible job.

P

Pip · Guide

Talks, points, builds the 3D model, draws the outcome. The only one the user talks to.

S

Scout · Investigate

Reads SCADA history, maintenance log, OEM manual, weather forecast. Returns evidence cards with sources.

B

Bolt · Act

Plans the fix, fills the CMMS work order, reserves the part. Can't submit; it can only request approval.

G

Gate · Govern (code, not an LLM)

Role policy, spend limits, Touch ID, hash-chained audit log. Deterministic on purpose, and say so: "the guardrail is not a prompt."

These are the four required stages (ingest → decide → act → report), with the human approval step in between. Put this exact diagram on the PPT.

What's real, what's staged, in what order.

Rule: staged inputs, real agents. The dashboard and CMMS are our own pages and the data is a replay. But the agents really reason over the data, really fill the form, and really ask for approval.

P0: without these there's no demo

  • Turbine 3D scene, hardcoded like the airplane in Spatial.swift: tower, nacelle, hub, 3 blades, shaft, gearbox, bearing. Build order and narration per step. hand-built
  • Full-screen transparent overlay for the 3D window, plus a red pulsing emission on the bearing and auto-Spread. change existing SpatialWindow
  • Wind-farm dashboard page: 12 tiles, replaying a CSV, T-07 goes red at second 5. local HTML + CSV
  • Scout: one LLM call with the CSV slice + maintenance log + one manual page, returning JSON evidence cards and a diagnosis. real LLM
  • CMMS page + Bolt: Bolt returns field values; the page fills them with an animated cursor; Submit stays locked. real LLM our page
  • Gate: role check + Touch ID (LocalAuthentication) + JSONL audit log with a SHA-256 chain. real
  • Demo mode switch: cached LLM responses so the demo still runs if the Wi-Fi drops. must have

P1: these turn it from good to winning

  • Real wind forecast from Open-Meteo (free, no key) to pick the lowest-wind window. real API
  • ROI sketch board + ₹ counter using the existing drawing boards. reuse
  • Task board showing Scout / Bolt / Pip status. simple view
  • One-page PDF report with the diagnosis, evidence, approval and audit hash. reuse SVG export

P2: only if P0 + P1 are rehearsed

  • Chiller pump swap: second 3D scene + chiller_pump.yaml. If you skip it, show the YAML on a slide and say "same agents."
  • Real SCADA replay from an open wind-farm dataset (for example Kelmarsh on Zenodo) instead of synthetic data.
Make it impossible to fail

Demo-proofing.

Record the MP4 first

The MP4 is required for submission anyway. Record the perfect run as soon as P0 works, and keep it on the desktop as your live backup.

Demo mode

One flag replays cached agent outputs with the same timing. Use the live mode only if the Wi-Fi is solid.

Rehearse 5 times with a timer

The 5 minutes is strict. Cut lines, not beats. The swap ending must happen.

Projector check

The transparent overlay needs contrast. Use the dark dashboard background, white parts and a red fault.
